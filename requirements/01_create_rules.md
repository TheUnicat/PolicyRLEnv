# Create — Hard Rules

What the benchmark must contain. Every item is mandatory.

## Tasks

- Create **exactly three tasks** in **one synthetic operations domain**.
- At least one task must require the agent to **refuse, ask for missing information, or escalate** instead of doing what the user asks.

## Per-task artifacts

Each task must include all of:

- User request
- Policy document
- Fake tool docs
- Starting database JSON
- Expected final state
- Final user-facing response

## Suggested task shapes (from the brief)

- Partial refund under policy.
- Procurement request that needs approval before purchase.
- Account change that requires missing verification information.

These are suggestions — the domain and exact tasks can differ as long as the rules above are met.
