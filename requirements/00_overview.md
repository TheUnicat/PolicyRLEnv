# Overview

## Challenge

**Policy Tool-Use Agent Benchmark** — Deep24

- **Difficulty:** Intermediate
- **Status:** Open
- **Category:** Agent Benchmarks
- **Skills:** agent engineering, evals, tool use, operations

## Description

Create tool-use tasks where an agent must follow policy, update the right state, and fail in inspectable ways.

## Goal

Build a synthetic operations benchmark where an agent must follow a written policy, use tools correctly, and end in the right state. Find policy and tool-use failures, then write a rubric or final-state checker.

## Time

2 to 3 hours.

## What "good" means

> A good benchmark is fair, reproducible, specific, verifiable, safe, and failure-rich.
