# Good Benchmark Checklist

The six quality criteria from the brief. Every task in the benchmark should be defensible against each one.

- **Fair** — policy and tool docs contain all rules needed.
- **Reproducible** — reviewers can inspect the same starting and final JSON.
- **Specific** — correct tool sequence or final state is defined.
- **Verifiable** — final-state checker catches wrong updates.
- **Calibrated** — a careful human can pass, but models can fail for policy/tool reasons.
- **Synthetic** — no real customer, employee, payment, order, or account data.
