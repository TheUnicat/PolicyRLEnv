# Submission Files — Hard Rules

What must be submitted. From the brief, verbatim.

| File | Include |
| --- | --- |
| **Benchmark Spec** | 3 task instructions, inputs, target failures, output format, grading rules |
| **Success Cases and Rubric** | manual answers, evidence, rubric, partial-credit rules |
| **Agent Build Trace** | how you designed the benchmark and built the agent |
| **Agent Run Trace** | model attempts, tool calls, wrong turns, retries |
| **Run Outputs and Failure Catalog** | final model answers, failures, evidence, severity, rubric checks |
| **Code, Prompts, or Repo** | prompts, agent code, validators, final-state checkers, workflow setup |
| **Source Materials** | public/synthetic inputs and source links |
